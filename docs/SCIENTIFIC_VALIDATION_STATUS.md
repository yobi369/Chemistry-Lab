# Scientific capability and validation status

**Status: advanced research-software prototype; not independently certified for scientific publication or operational laboratory decisions.** This document distinguishes implemented numerical/software capabilities from validation that is still outstanding.

The Qin Model 4 uncertainty work now includes a stratified experimental-condition cluster bootstrap. See [Qin 2018 bootstrap uncertainty](QIN_2018_BOOTSTRAP_UNCERTAINTY.md) for the resampling unit, interpretation, reproducibility command and limitations. CI runs both a deterministic 20-replicate smoke test and a 500-replicate × 3-seed extended stability experiment. The extended bootstrap is still exploratory, not a publication-grade interval calculation.


The Qin Model 4 conditional profile-likelihood implementation is described in [Qin 2018 profile-likelihood diagnostics](QIN_2018_PROFILE_LIKELIHOOD.md). It is an exploratory diagnostic, not a calibrated publication interval: the likelihood-ratio assumptions and candidate observation selection remain open validation items.


The expanded Qin uncertainty workflow archives a 500-replicate-per-seed, three-seed cluster-bootstrap report (1,500 resamples per model). Seed-specific percentile endpoints and optimizer-bound hit frequencies are retained separately; seed-to-seed ranges are reported only as stability diagnostics, not confidence intervals.


Historical 200-replicate run (superseded by the later 500×3 experiment): on the corrected 31-condition / 279-observation set, the 200-replicate, three-seed Qin Model 4 experiment completed with 600/600 converged fits for both 4L and 4G. Lower-bound hit rates include 4L Beijing k2 60.5%, 4L Hepure k2 39.7%, 4G Beijing k2 25.5%, and 4G Hepure k2 38.2%. The 97.5th-percentile endpoint spread across seeds was 49.9% for 4L CMC-nZVI k2 and 17.4% for 4G CMC-nZVI k2. See [Qin 2018 bootstrap uncertainty](QIN_2018_BOOTSTRAP_UNCERTAINTY.md) for all frequencies and endpoint ranges. This reinforces the weak-identifiability caveat rather than establishing narrow or publication-ready intervals.


An audit of the original Qin–Tratnyek 2018 supporting information found that Model 4 Tables S5 and S6 list 31 local experimental conditions. The 35-series raw CSV includes four additional CMC-nZVI dithionite/thiosulfite series (#64, #65, #68, #69) that are absent from those Model 4 coefficient tables. The current Model 4 benchmark therefore uses the 31 listed conditions and all nine time points per condition (279 observations). This yields 72 fitted parameters and 207 df for 4L, and 68 parameters and 211 df for 4G, matching the published table. The earlier 35-series / 287-point bootstrap and profile artifacts are superseded; direct author confirmation of the exact row-level inclusion rule remains outstanding.


The corrected 81-point profile run with 24-step log-space endpoint refinement on the 31-condition set finds boundary-limited and, in several cases, disconnected accepted regions. 4L Beijing and Hepure have low-rate primary regions plus high-rate disconnected regions reaching 10 h^-1. 4G Beijing has a high-rate primary region containing its fitted estimate and a disconnected low-rate region reaching 1e-8 h^-1; 4G Hepure has a low-rate primary region and a high-rate disconnected region reaching 10 h^-1. These are boundary-limited diagnostics, not finite two-sided confidence intervals. See [Qin 2018 profile-likelihood diagnostics](QIN_2018_PROFILE_LIKELIHOOD.md).

The full observation-selection rationale and candidate comparison are documented in [Qin 2018 observation-selection audit](QIN_2018_OBSERVATION_SELECTION_AUDIT.md).

The corrected Qin Model 4 benchmark now compares every one of the 279 TypeScript fitted observations against an independent SciPy fit. The 4L prediction RMSE is 7.39e-5 µmol (maximum absolute difference 4.48e-4 µmol); the 4G RMSE is 1.77e-6 µmol (maximum 9.49e-6 µmol). Residual correlations exceed 0.99999999 and relative residual-SSE differences are below 5e-9. Row-level prediction/residual differences are archived and gated in CI. See [Qin 2018 prediction validation](QIN_2018_PREDICTION_VALIDATION.md). This confirms implementation agreement, not parameter identifiability or mechanistic validity.


The stiff kinetic fitter now supports an opt-in adaptive implicit integration path while preserving RK4 as the default. A synthetic A→B→C fit with k1=800 s^-1 and k2=0.03 s^-1 is checked against an independent SciPy BDF + bounded least-squares reference. The final trajectory diagnostics and rejected integration-trial count are exposed in the fit result. These remain synthetic validation cases, not broad certification for stiff reaction networks.


The first stiff-fit fixture uses k1=800 s^-1 and k2=0.03 s^-1. Its SciPy BDF reference recovers 800.00000049 and 0.030000000018 s^-1 with weighted RSS 3.89e-14. The TypeScript adaptive implicit fitter passes parameter and prediction tolerances, returns solver diagnostics, and reports zero failed trial integrations. This is limited synthetic evidence; additional stiff mechanisms and tolerance-refinement studies remain necessary.


## Latest independent validation extension (3 November 2026)

The 500×3 Qin Model 4 bootstrap, 81-point profile-likelihood run, complete SciPy prediction comparisons, reversible stiff-network validation and RDKit browser/CSP/offline tests all passed in GitHub Actions workflow run `41635161445`. The reversible-network tests are synthetic and strengthen a narrow class of fast reversible/slow-drain systems; they do not certify arbitrary stiff chemical networks.

The 2-D finite-volume diffusion solver now has an independent multi-resolution reference programme. SciPy 1.17.0 BDF and Radau are run on sparse method-of-lines operators at 8×8, 16×16, 32×32 and 64×64 meshes. The TypeScript explicit finite-volume solver is compared at the same cell centres with the exact semi-discrete cosine eigenmode. The maximum explicit-vs-BDF errors decrease from approximately 1.20×10⁻⁵ to 1.86×10⁻⁷ across the four meshes, with successive refinement ratios above 3.7; BDF/Radau reference differences remain below 3×10⁻¹¹. The CI report is archived as `spatial2d-scipy-mesh-convergence`. This validates the tested constant-coefficient no-flux diffusion mode, not the full range of 2-D transport/reaction physics.
