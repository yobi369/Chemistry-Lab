# Scientific capability and validation status

**Status: advanced research-software prototype; not independently certified for scientific publication or operational laboratory decisions.** This document distinguishes implemented numerical/software capabilities from validation that is still outstanding.

The Qin Model 4 uncertainty work now includes a stratified experimental-condition cluster bootstrap. See [Qin 2018 bootstrap uncertainty](QIN_2018_BOOTSTRAP_UNCERTAINTY.md) for the resampling unit, interpretation, reproducibility command and limitations. The CI bootstrap is a deterministic smoke check, not a publication-grade interval calculation.


The Qin Model 4 conditional profile-likelihood implementation is described in [Qin 2018 profile-likelihood diagnostics](QIN_2018_PROFILE_LIKELIHOOD.md). It is an exploratory diagnostic, not a calibrated publication interval: the likelihood-ratio assumptions and candidate observation selection remain open validation items.


The expanded Qin uncertainty workflow archives a 200-replicate-per-seed, three-seed cluster-bootstrap report. Seed-specific percentile endpoints and optimizer-bound hit frequencies are retained separately; seed-to-seed ranges are reported only as stability diagnostics, not confidence intervals.


On the corrected 31-condition / 279-observation set, the 200-replicate, three-seed Qin Model 4 experiment completed with 600/600 converged fits for both 4L and 4G. Lower-bound hit rates include 4L Beijing k2 60.5%, 4L Hepure k2 39.7%, 4G Beijing k2 25.5%, and 4G Hepure k2 38.2%. The 97.5th-percentile endpoint spread across seeds was 49.9% for 4L CMC-nZVI k2 and 17.4% for 4G CMC-nZVI k2. See [Qin 2018 bootstrap uncertainty](QIN_2018_BOOTSTRAP_UNCERTAINTY.md) for all frequencies and endpoint ranges. This reinforces the weak-identifiability caveat rather than establishing narrow or publication-ready intervals.


An audit of the original Qin–Tratnyek 2018 supporting information found that Model 4 Tables S5 and S6 list 31 local experimental conditions. The 35-series raw CSV includes four additional CMC-nZVI dithionite/thiosulfite series (#64, #65, #68, #69) that are absent from those Model 4 coefficient tables. The current Model 4 benchmark therefore uses the 31 listed conditions and all nine time points per condition (279 observations). This yields 72 fitted parameters and 207 df for 4L, and 68 parameters and 211 df for 4G, matching the published table. The earlier 35-series / 287-point bootstrap and profile artifacts are superseded; direct author confirmation of the exact row-level inclusion rule remains outstanding.


The corrected 41-point profile run on the 31-condition set finds all four targeted phase-2 rate profiles reaching the 1e-8 h^-1 lower bound. Model 4L Beijing and Hepure each show an additional disconnected accepted region extending to the 10 h^-1 upper bound; the 4G profiles are single connected regions on the evaluated grid. These are boundary-limited diagnostics, not finite two-sided confidence intervals. See [Qin 2018 profile-likelihood diagnostics](QIN_2018_PROFILE_LIKELIHOOD.md).

The full observation-selection rationale and candidate comparison are documented in [Qin 2018 observation-selection audit](QIN_2018_OBSERVATION_SELECTION_AUDIT.md).
