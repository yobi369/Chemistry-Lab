# Security policy

Chemistry Lab is research software and should not be treated as a certified or safety-critical chemistry system.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Use GitHub's **Private vulnerability reporting** feature for this repository if it is enabled. If it is unavailable, contact the repository maintainer through a private channel and include reproduction steps, affected versions, and potential impact.

Please allow the maintainer reasonable time to investigate and prepare a fix before public disclosure.
